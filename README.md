# Habbad Quiz

Projet React prêt à être déployé avec Vercel ou Netlify.

## Lancer en local
1. Installer Node.js (version 18 ou plus récente).
2. Dans ce dossier, lancer `npm install`.
3. Lancer `npm run dev`.

## Déployer sur Vercel
1. Importer ce dossier dans un dépôt GitHub.
2. Sur Vercel, choisir **Add New → Project** puis importer le dépôt.
3. Laisser les réglages détectés automatiquement (Build Command: `npm run build`, Output Directory: `dist`).
4. Cliquer sur **Deploy**.
